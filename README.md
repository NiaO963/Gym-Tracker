# Four-Day Gym Tracker

A free, no-signup workout tracker for a four-day split focused on a strong back, glutes and core.

| Day | Where | Focus |
| --- | --- | --- |
| 1 | Gym | Pull & Posture |
| 2 | Gym | Lower Body Power |
| 3 | Home | Calisthenics & Cardio |
| 4 | Gym | Upper Body & Core |

## Features

- Tap-to-log set circles with a progress bar
- Rest timer that starts when you finish a set
- Interval timer for each day's cardio finisher
- Demo and muscle-image links for every exercise
- Keep-screen-awake option for the gym
- After-workout recap with muscles trained, rest and eating tips

## Use it

Open the live site (see the repository's About link), choose today's day, and tap the circles as you finish each set. Your progress and weights are stored in your own browser and are never uploaded.
